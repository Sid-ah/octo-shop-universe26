# Octo Shop

A tiny Node.js store used for the GitHub Universe 2026 demos.

> ⚠️ **Intentionally buggy and vulnerable. Never deploy it.** It contains a pricing bug (Demo 3),
> command injection, path traversal, SQL injection, AI-app issues, and a vulnerable lodash version (Demo 7).

```bash
npm install
npm test        # 4 pass, 1 todo (the UNIVERSE26 double-discount bug)
npm start       # http://localhost:3000/api/health
```
